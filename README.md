# 상승 종목 원인·파급 분석 파이프라인

최근 주가가 강하거나 상승 전환한 KRX 종목을 스크리닝하고, 상승 **원인**을 뉴스·공시로 분류한 뒤,
원인이 **산업 공통 요인**일 때 동종업계·전방·후방 산업의 수혜 후보를 예측하는 자동화 파이프라인.

## 파급에는 두 개의 축이 있다

이 파이프라인의 핵심 설계입니다.

**수직축 (밸류체인)** — 제품·물량이 흐르는 경로(후방 소재·부품 ↔ 기업 ↔ 전방 수요처).
수주·공급계약처럼 물량이 전이되는 원인에서 작동하며 **시차가 있습니다**(조선 수주 →
기자재 발주까지 6~12개월). 시차 덕분에 선점 기회가 큽니다. `valuechain/*.yaml`이 근거입니다.

**수평축 (공통 동인)** — 같은 매크로·정책·원자재 동인에 노출된 기업 집합으로,
**섹터를 관통합니다.** AI 데이터센터 동인 하나가 반도체·전력기기·건설·공조·전선·원전을
동시에 건드리는데, KRX 업종 분류로는 이게 전부 흩어져서 잡히지 않습니다. 업황·정책·원자재
원인에서 작동하고 **동시에 반응**합니다. 테마지수·ETF 구성종목과 팩터 베타가 근거입니다.

원인 유형이 어느 축을 탈지 결정합니다. 수주·공급계약이면 수직, 업황·정책·원자재면 수평입니다.

수평축에서는 두 가지가 결정적입니다. **첫째, 부호**입니다. 구리 상승은 비철 제련에 수혜지만
전선에는 원가 부담이므로 무조건 수혜로 몰면 반대 방향으로 갑니다. **둘째, 동시성** 때문에
목록만으로는 알파가 없습니다. 실제 기회는 "노출도는 높은데 아직 반응하지 않은 종목"이고,
이걸 **갭**으로 정량화합니다.

```
갭 = 기대수익률 − 실제수익률
기대수익률 = β_시장 × 시장 최근수익률 + β_그룹 × 그룹고유 최근수익률
```

시장 요인을 분리하지 않으면 모든 종목이 시장을 통해 서로 상관되어 그룹과 무관한 종목까지
'미반영'으로 잡히므로, 그룹 수익률에서 시장 성분을 제거한 잔차를 그룹 고유 요인으로 씁니다.

## 동작 흐름

```
1. 스크리닝 (src/screener.py)     pykrx로 전 종목 가격 수집 → 강세지속/상승전환 시그널 → 상위 30종목
2. 수평 그래프 (src/groups.py,    KRX 테마지수 + 섹터·테마 ETF PDF로 섹터 초월 그룹 구성
              src/factors.py)     매크로 팩터(환율·구리·유가·금리) 베타 = 부호 있는 노출도
                                  2팩터 모델로 그룹별 미반영 갭 산출
3. 근거 수집 (src/collect.py)     네이버 뉴스 API + DART 공시 목록
4. 원인 분석 (src/analyze.py)     Claude API — 원인 7유형 분류 + 회사고유/산업공통 판정
                                  + 수직/수평 축 판정 → 파급 경로와 수혜·피해 후보 도출
                                  갭을 근거로 미반영 판정 후 종합 아이디어 생성
5. 리포트 (src/report.py)         reports/YYYYMMDD.html (GitHub Pages) + cases/ JSON 축적
6. 알림 (src/notify.py)           텔레그램 요약 발송 (+ Pages 링크)
```

**회사 고유 이슈로 오른 종목은 파급 예측에 쓰지 않습니다.** 산업 공통 요인만 확장하며,
이미 같이 오른 후보는 '기반영'으로 강등합니다.

## 로컬 실행

```bash
pip install -r requirements.txt
python -m src.pipeline                    # 오늘 기준 전체 실행
python -m src.pipeline --skip-analyze     # 스크리닝+수평그래프+리포트만 (LLM 키 불필요)
python -m src.pipeline --skip-horizontal  # 수평 그래프 생략 (빠른 확인용)
python -m src.pipeline --date 20260724    # 특정일 기준
```

수평 그래프는 **가격 데이터만으로 계산되므로 API 키가 전혀 필요 없습니다.** LLM 키가 없어도
그룹별 미반영 갭 랭킹은 리포트에 그대로 나옵니다.

## 자동 실행 (GitHub Actions)

`.github/workflows/daily-screen.yml`이 **평일 17:10 KST**에 파이프라인을 실행하고,
결과를 커밋한 뒤 `reports/`를 GitHub Pages로 배포한다. Actions 탭에서 수동 실행(workflow_dispatch)도 가능.

### 필요한 설정

**1. Repository Secrets** (Settings → Secrets and variables → Actions):

| Secret | 필수 | 용도 |
|---|---|---|
| `KRX_ID` / `KRX_PW` | 권장 | KRX 정보데이터시스템([data.krx.co.kr](https://data.krx.co.kr)) 계정. 최근 KRX가 대량 조회에 로그인을 요구해, 미설정 시 가격 수집이 실패할 수 있음 |
| `ANTHROPIC_API_KEY` | 권장 | 원인 분석·파급 추론. 없으면 스크리닝만 수행 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 권장 | 뉴스 수집 ([developers.naver.com](https://developers.naver.com)에서 검색 API 앱 등록) |
| `DART_API_KEY` | 선택 | 공시 수집 ([opendart.fss.or.kr](https://opendart.fss.or.kr) 무료 발급) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | 선택 | 텔레그램 알림 (@BotFather로 봇 생성 후 토큰, 봇과 대화 시작 후 chat_id 확인) |

**2. GitHub Pages 활성화**: Settings → Pages → Source를 **GitHub Actions**로 설정.

## 설정 조정

`config.yaml`에서 스크리닝 임계값(시총·거래대금 하한, 수익률·거래량 기준), 수평 그래프
파라미터(베타 구간, 갭 판정 구간, 최소 상관), 분석 대상 수, 모델 등을 조정합니다.

### 팩터 추가

`horizontal.factors`에 이름과 키워드만 적으면 됩니다. 팩터 대용치는 전부 **국내 상장
ETF/ETN**이라 별도 데이터 소스가 필요 없고, 티커를 하드코딩하지 않고 **종목명 키워드로
런타임에 해석**하므로 상품이 새로 상장되거나 폐지돼도 깨지지 않습니다. 매칭되는 상품이
없으면 해당 팩터만 조용히 건너뜁니다.

```yaml
- name: 리튬
  keywords: [리튬]
  exclude: [인버스, 레버리지]
```

## 수직축: 밸류체인 맵 확장

`valuechain/*.yaml`이 수직축 추론의 지식베이스입니다. 현재 건설·EPC, 전력기기, 조선, 반도체,
방산, 이차전지 6개 산업이 시드로 들어 있습니다. 산업 추가 시 같은 형식(peers / upstream /
downstream / notes)으로 파일을 추가하면 자동 반영됩니다.

동종업계(peers)는 수평축의 테마·ETF 그룹이 이미 자동으로 커버하므로, 맵을 늘릴 때는
**upstream/downstream과 notes에 집중**하는 게 효율적입니다. DART 사업보고서의 매출처·원재료
비중으로 notes를 보강할수록 수혜 후보의 정확도가 올라갑니다.

## 케이스 축적

매 실행마다 `cases/YYYYMMDD.json`에 후보·분석·아이디어가 쌓인다. 장기적으로
"수주 모멘텀형 상승은 N주 후 후방 기자재로 파급" 같은 시차 패턴 백테스트에 활용할 수 있다.
