## 0. 결론 먼저

1. **DART 전수조사는 이번 작업 환경에서 완료하지 못했다.** 작업 환경(클라우드 샌드박스)의 네트워크 정책이 `dart.fss.or.kr`, `opendart.fss.or.kr`, `kind.krx.co.kr`와 언론사 사이트 접속을 모두 차단했다(프록시 403 응답 확인). 그래서 DART 원문 표를 한 줄씩 읽는 "전수조사"는 수행할 수 없었다.
2. 대신 **뉴스 검색(네이버 뉴스 검색 API, 웹 검색)**으로 같은 회사·같은 기간의 데이터센터 시공 계약을 조사해, **제공 목록에 없는 후보 9건**과 **목록에 있으나 분기 커버리지가 비어 보이는 항목 13건**을 찾았다(아래 2절·3절).
3. 후보 중 근거가 가장 강한 것은 다음 5건이다. 모두 "데이터센터"라는 단어가 공사명에 없어서 키워드 검색에서 빠졌을 가능성이 있는 유형이거나(①②③), 자회사 수주라서 빠졌을 가능성이 있는 유형(④)이다.
   - ① 현대건설 – **KB국민은행 통합IT센터**(김포, 2017.9 시공사 선정, 약 1,800억, 2019.7 준공)
   - ② 현대건설 – **국가정보자원관리원 대구센터 신축공사**(정부통합전산센터, 2018 시공사 선정·2019.9 착공, 현대건설분 1,417억)
   - ③ GS건설 – **대구은행 DGB혁신센터 신축공사**(DGB금융 차세대 데이터센터, 2017.4 수주 약 715억, 2018 준공)
   - ④ DL건설 – **가산아이윌 데이터센터 신축공사**(2022.7 수주, DL건설 지분 약 1,028억; DL이앤씨 연결 보고서에도 실릴 수 있음)
   - ⑤ 삼성물산 – **삼성SDS 춘천 데이터센터**(2017 착공, 2019.9 개관, 총 투자 985억)
4. 실제 DART 원문에 위 항목들이 어떤 공사명으로 실려 있는지(또는 실려 있지 않은지)는 **DART 접속이 되는 환경에서 `tools/dart_dc_census.py`를 실행해 확인**해야 한다(5절). 뉴스에 시공 사실이 있어도 회사가 정기보고서 수주 표에 그 공사를 싣지 않았을 수 있기 때문에, 이 문서의 후보는 "DART 확인 대상"이지 "DART에 있다고 확인된 것"이 아니다.

## 1. 이번 작업에서 한 것과 못 한 것

| 구분 | 내용 |
|---|---|
| 한 것 | 네이버 뉴스·웹 검색 및 웹 검색으로 8개 회사의 2017~2022년 데이터센터 시공 계약 후보 조사(검색 약 90회) |
| 한 것 | 제공 목록의 회사별·공사별 분기 커버리지 점검(어느 분기에만 나타나는지) |
| 한 것 | DART 전수조사 스크립트 작성(`tools/dart_dc_census.py`, `tools/dart_lib.py`) |
| 못 한 것 | DART 정기보고서 원문(수주상황 표) 직접 열람. 네트워크 차단으로 불가 |
| 못 한 것 | 위 스크립트의 실제 DART 응답 검증. 문법 검사와 키워드 분류 함수 단위 테스트만 수행 |

DART 차단 확인 기록: `curl https://dart.fss.or.kr/...` → 프록시 `CONNECT tunnel failed, response 403`; 프록시 상태 페이지에 `dart.fss.or.kr:443 connect_rejected (policy denial)` 기록. `WebFetch` 도구도 `EGRESS_BLOCKED` 반환.

## 5. DART 전수조사 방법 (DART 접속이 되는 PC에서 실행)

```bash
cd <이 저장소>
python3 tools/dart_dc_census.py --out out/            # 8개 회사 × 2017Q1~2022Q4 전체
python3 tools/dart_dc_census.py --out out/ --company 현대건설   # 한 회사만
```

동작 방식
1. DART 검색(`dsab007/detailSearch.ax`)을 연도별로 호출해 분기·반기·사업보고서 접수번호(rcpNo)를 모은다. **원본과 [기재정정]본을 모두** 대상으로 한다.
2. 각 보고서의 문서 트리에서 `수주`, `사업의 내용`, `건설계약`, `매출 및 수주` 등이 들어간 노드를 내려받는다(오래된 보고서는 `II. 사업의 내용` 하나에 다 들어 있음).
3. 노드 안의 **모든 표의 모든 행**을 읽어 키워드를 대조한다. `strong`(데이터센터·IDC·HPC·IT센터·전산센터·정보자원관리원·혁신센터·주요 발주처명 등)과 `weak`(DC·센터·클라우드·발주처 약칭 등)로 나눠 `out/hits.csv`에 쓴다.
4. 보고서를 못 찾은 분기는 `out/missing.csv`에, 사용한 보고서 목록은 `out/reports.csv`(DART URL 포함)에 쓴다.

주의: 이 스크립트는 실제 DART 응답으로 검증하지 못했다(차단 환경). 실행 중 오류가 나면 `tools/dart_lib.py`의 검색·노드 파싱 정규식을 현재 DART 페이지 구조에 맞게 손봐야 할 수 있다.

## 6. 용어 설명 (비전공자용)

- **DART**: 금융감독원 전자공시시스템. 상장회사와 일정 규모 이상 회사가 사업보고서 등을 올리는 공식 사이트.
- **정기보고서**: 분기보고서(1분기·3분기), 반기보고서(2분기), 사업보고서(연간, 4분기 시점). 2022Q4 = 2022년 사업보고서(2023년 3월 제출).
- **수주현황(수주상황) 표**: 정기보고서 "사업의 내용" 안에 있는 표로, 회사가 따낸 공사 목록(공사명·발주처·계약일·완공예정일·기본도급액·완성공사액·계약잔액)을 보여준다.
- **기본도급액 / 완성공사액 / 계약잔액**: 총 계약금액 / 지금까지 공사해서 매출로 인식한 금액 / 아직 남은 금액. 단위는 회사마다 백만원 또는 원.
- **[기재정정]**: 이미 낸 보고서를 고쳐서 다시 낸 것. 같은 분기에 두 개가 있으면 정정본이 최신.
- **연결 기준**: 자회사까지 합쳐서 보는 것. DL이앤씨 보고서의 수주 표에 자회사 DL건설의 공사(상암·가산아이윌 등)가 함께 실릴 수 있다.
- **IDC / DC / HPC센터 / 통합IT센터 / 전산센터**: 모두 서버(컴퓨터)를 모아 두고 운영하는 건물, 즉 데이터센터를 부르는 여러 이름. 회사·발주처마다 표기가 달라 키워드 검색에서 빠지기 쉽다.
- **프리콘(Pre-construction)**: 설계 단계부터 시공사가 참여하는 발주 방식. GS건설 하나금융·DGB혁신센터 기사에 나오는 용어.

## 7. 자가 검토 (이 문서의 한계와 오류 가능성)

1. 뉴스가 "시공했다"고 해도 회사가 정기보고서 수주 표에 그 공사를 싣는다는 보장은 없다(표에 금액 하한을 두는 회사가 있다). 따라서 2절은 **DART 확인 대상 목록**이다.
2. A5(삼성SDS 춘천)의 시공사 근거는 2023~2024년 회고 기사이며, 2017~2019년 당시 계약 보도는 찾지 못했다. 삼성SDS의 자체 투자 보도(985억)를 삼성물산 도급액으로 오해하면 안 된다.
3. A2(국가정보자원관리원 대구센터)는 조달청 입찰이 2019년 감사원 지적으로 한 차례 취소·재개된 이력이 있어, 최종 계약 시점과 금액은 DART 원문으로 확인해야 한다.
4. 3절의 "비어 있는 분기"는 회사의 공시 기준 변경으로 정상일 수 있다. 특히 현대건설은 세 분기에만 몰려 있어 추출 누락이 의심되지만 단정할 수 없다.
5. 검색 도구 한계: 네이버 뉴스 검색은 최신 기사 위주로 반환하고 한 번에 최대 100건만 준다. 2017~2019년 지방지·전문지 보도는 놓쳤을 수 있다.
6. 이 문서에 적은 URL은 검색 결과에 포함된 인용문(설명문)을 기준으로 골랐다. 검색 결과 요약문은 기사 본문에서 발췌된 것이지만, 본문 전체를 열어 대조하지는 못했다(언론사 사이트 접속 차단).
